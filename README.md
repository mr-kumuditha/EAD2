## Overview
EAD2 is a hybrid event management project with a Java Spring backend and a React + TypeScript frontend.  
It helps you learn full-stack development using clean and modern tools.

---

## Project Structure
```

EAD2/
├── frontend/         # React + Vite client
├── backend/          # Java Spring Boot backend
└── README.md

````

## Getting Started

### Prerequisites
You need:

| Tool | Version |
|------|---------|
| Node.js | 16+ |
| npm | latest |
| Java | 11+ |
| Maven | latest |

---

## Installation

Clone the repository:
```bash
git clone https://github.com/mr-kumuditha/EAD2
cd EAD2
````

### Install frontend dependencies:

```bash
cd frontend
npm install
```

### Install backend dependencies:

```bash
cd ../backend
mvn install
```

---

## Usage

### Run frontend:

```bash
cd frontend
npm start
```

### Run backend:

```bash
cd backend
mvn spring-boot:run
```

Or run the built jar:

```bash
java -jar target/ead2-backend.jar
```

---

## Testing

### Frontend tests:

```bash
cd frontend
npm test
```

### Backend tests:

```bash
cd backend
mvn test
```
